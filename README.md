# java-racingcar-precourse

# 구현할 기능 목록

## 1. 입력 기능

- 자동차 이름 입력
- 시도 횟수 입력

## 2. 출력 기능

- 첫번째 프롬프트 "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"
- 두번째 프롬프트 "시도할 횟수는 몇 회인가요?"
- 차수별 실행 결과 출력
- 우승자 출력(단독 또는 공동 우승)

## 3. 자동차 클래스

- 자동차는 전진 또는 멈출 수 있다.
- 자동차에 이름을 부여할 수 있다. (자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.)
- 자동차를 출력할 수 있다.

## 4. 예외 처리 기능

- 자동차 이름 입력 검증
- 시도 횟수 입력 검증

## 5. Controller

- InputView와 OutputView, Validator, Car 객체를 사용하여 게임의 전체 흐름을 관리한다.
- 사용자가 입력한 자동차 이름과 시도 횟수를 기반으로 레이스를 진행한다.
- 각 차수별 자동차의 전진/멈춤 상태를 업데이트하고, OutputView를 통해 차수별 결과를 출력한다.
- 최종 우승자를 결정하고, OutputView를 통해 출력한다.
